## Underrated context (Crash Course skips this)

- **Programming the ENIAC took weeks.** It meant physically rewiring patch cables for each new program. Six women — "the ENIAC Six" — did this work. They were the first programmers and were excluded from press photos for decades.
- **Grace Hopper invented the compiler when people said it was impossible.** The dominant belief in 1950 was that computers couldn't translate human-readable code — "computers can only do math, not translate language." She proved them wrong with A-0 (1952).
- **FORTRAN was a productivity revolution.** Before FORTRAN (1957), scientific code took weeks to write in assembly. With FORTRAN, hours. Many scientists initially refused to use it ("real programmers use machine code"). Sound familiar?
- **The von Neumann bottleneck.** Storing code + data in the same memory means the CPU spends most time waiting on memory access. This bottleneck still defines computing. Caches and pipelining exist to fight it.
- **Hopper's other gifts.** "Nanosecond" wire (~30cm, distance light travels in 1ns), the term "debugging" (the moth), COBOL.
