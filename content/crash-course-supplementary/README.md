## Convention

Each episode file follows the same skeleton:

1. **Underrated context** — what Crash Course glosses over
2. **Videos** — best supplementary watches
3. **Articles** — short reads
4. **Books** — go-deep options
5. **Interactive / hands-on**
6. **Time budgets** — 30min / 2hr / weekend / long-term tiers
7. **Open questions** — your own notes

## Suggested viewing order

- **Linear (recommended for first pass)**: Ep 1 → 40 in order. Crash Course is designed this way.
- **Architecture-first**: Ep 1–10 → CSAPP / nand2tetris / Ben Eater → return to Ep 11+ later.
- **Software-first**: Ep 1–2 → skip to Ep 10–18 → fill in hardware on-demand.

If unsure → just go linear.
